# Re:write - Product Require Document

## 1. 서비스 목적

- Re:write는 취업 준비생이 자기소개서를 작성하고, AI 첨삭을 통해 문장 개선, 키워드 분석, 예상 면접 질문 생성까지 이어서 준비할 수 있도록 돕는 자기소개서 기반 취업 준비 서비스입니다.

## 2. 문제 정의

취업 준비생은 자기소개서를 작성할 때 다음과 같은 어려움을 겪습니다.

- 어떤 내용을 써야 할지 막막함
- 문장이 자연스러운지 판단하기 어려움
- 직무와 관련된 키워드가 충분히 포함되었는지 확인하기 어려움
- 자기소개서 작성 이후 면접 준비까지 연결하기 어려움
- 이전 버전과 수정 버전을 비교하며 개선 과정을 관리하기 어려움

## 3. 타겟 사용자

### 3.1 주요 사용자

- 신입 개발자 취업 준비생
- 자기소개서를 처음 작성하는 취준생
- 자기소개서 첨삭을 빠르게 받고 싶은 사용자
- 자기소개서를 기반으로 면접 질문까지 준비하고 싶은 사용자

### 3.2 사용자 니즈

- 자기소개서 문장 개선
- 직무 키워드 반영 여부 확인
- 자기소개서 버전 관리
- 예상 면접 질문 생성
- 꼬리 질문을 통한 면접 연습

### F-02: 내 자기소개서 목록(/writing)

#### 자기소개서 목록 조회

사용자가 작성한 자기소개서 목록을 카드 형태로 조회합니다.

- 목록은 Grid 형태로 표시합니다.
- 데스크톱 기준 3열 Grid로 표시합니다.
- 한 페이지에는 최대 9개의 자기소개서 카드를 표시합니다.
- 자기소개서가 9개를 초과하는 경우 페이지네이션을 제공합니다.

| 항목 | 설명 |
|---|---|
| 회사명 | 지원 회사명을 태그 형태로 표시합니다. |
| 직무 | 지원 직무를 태그 형태로 표시합니다. |
| 제목 | 자기소개서 제목을 표시합니다. |
| 첨삭 상태 | AI 첨삭 진행 상태를 표시합니다. 첨삭 상태는 작성 중, 첨삭 중, 첨삭 완료, 첨삭 실패로 나눠집니다. |
| 작성일 | 자기소개서 작성일 또는 수정일을 표시합니다. |

#### 자기소개서 카드 클릭

사용자가 자기소개서 카드를 클릭하면 해당 자기소개서 상세 페이지로 이동합니다.

#### 업로드 버튼 클릭

사용자가 새 자기소개서 작성 버튼을 클릭하면 자기소개서 등록 페이지로 이동합니다.


### F-03: 자기소개서 등록 폼(`/writing/create/step1`)

#### Step Indicator

현재 작성 단계와 진행 상태를 표시합니다.

| 단계 | 화면 표시 | 설명 |
|---|---|---|
| Step 1 | 직무 정보 | 자기소개서 제목, 회사명, 직무, 공고 링크를 입력합니다. |
| Step 2 | 우대사항 | 채용 공고의 우대사항을 입력합니다. |
| Step 3 | 자기소개서 작성 | 자기소개서 문항, 글자 수, 답변을 입력합니다. |
| Step 4 | 완료 | 입력한 내용을 최종 확인하고 제출합니다. |

- 현재 단계는 활성화 상태로 표시합니다.
- 이전 단계는 완료 상태로 표시합니다.
- 이후 단계는 비활성 상태로 표시합니다.

#### Step 1: 직무 정보 입력

##### 입력 항목

| 항목 | 설명 | 필수 여부 |
|---|---|---|
| 자기소개서 제목 | 자기소개서를 구분하기 위한 제목을 입력합니다. | 필수 |
| 회사명 | 지원할 회사명을 입력합니다. | 필수 |
| 직무 | 지원할 직무명을 입력합니다. | 필수 |
| 직무 공고 사이트 링크 | 지원 공고 URL을 입력합니다. | 선택 |

##### 주요 기능

- 자기소개서 제목을 입력할 수 있습니다.
- 회사명을 입력할 수 있습니다.
- 지원 직무를 입력할 수 있습니다.
- 직무 공고 사이트 링크를 입력할 수 있습니다.
- `다음` 버튼 클릭 시 Step 2로 이동합니다.
- `임시 저장` 버튼 클릭 시 현재 입력 내용을 저장합니다.

---

#### Step 2: 채용 우대사항 입력

##### 입력 항목

| 항목 | 설명 | 필수 여부 |
|---|---|---|
| 공고 우대사항 | 채용 공고에 작성된 우대사항을 입력합니다. | 필수 |

##### 주요 기능

- 채용 공고의 우대사항을 TextArea에 입력할 수 있습니다.
- 입력한 우대사항은 이후 AI 첨삭 및 키워드 분석에 활용됩니다.
- 뒤로가기 버튼 클릭 시 Step 1로 이동합니다.
- `다음` 버튼 클릭 시 Step 3으로 이동합니다.
- `임시 저장` 버튼 클릭 시 현재 입력 내용을 저장합니다.

---

#### Step 3: 자기소개서 문항 및 답변 입

##### 입력 항목

| 항목 | 설명 | 필수 여부 |
|---|---|---|
| 자기소개서 질문 | 자기소개서 문항을 입력합니다. | 필수 |
| 자기소개서 글자 수 | 자기소개서 제한 글자 수를 입력합니다. | 선택 |
| 자기소개서 내용 | 자기소개서 답변을 입력합니다. | 필수 |

##### 주요 기능

- 자기소개서 질문을 입력할 수 있습니다.
- 자기소개서 제한 글자 수를 입력할 수 있습니다.
- `적용` 버튼 클릭 시 입력한 제한 글자 수가 답변 영역의 기준 글자 수로 반영됩니다.
- 자기소개서 내용을 입력할 수 있습니다.
- 현재 입력한 글자 수와 제한 글자 수를 표시합니다.
- 문항을 추가할 수 있습니다.
- 여러 개의 자기소개서 문항을 작성할 수 있습니다.
- 각 문항은 접기/펼치기 형태로 표시할 수 있습니다.
- `다음` 버튼 클릭 시 Step 4로 이동합니다.
- `임시 저장` 버튼 클릭 시 현재 입력 내용을 저장합니다.

##### 문항 추가

사용자가 `문항 추가` 버튼을 클릭하면 새로운 자기소개서 문항 입력 영역이 추가됩니다.

추가되는 항목은 다음과 같습니다.

| 항목 | 설명 |
|---|---|
| 질문 | 자기소개서 문항 입력 |
| 글자 수 | 해당 문항의 제한 글자 수 입력 |
| 내용 | 해당 문항에 대한 자기소개서 답변 입력

---

##### 확인 항목

| 항목 | 설명 |

- 뒤로가기 버튼 클릭 시 이전 단계로 이동합니다.
- `완료` 버튼 클릭 시 최종 제출 확인 모달을 표시합니다.
- 제출 완료 시 자기소개서가 저장됩니다.
- 저장 완료 후 자기소개서 상세 페이지로 이동합니다.

### F-04: 자기소개서 상세 페이지(`/writing/[id]`)

#### 자기소개서 상세 조회

| 항목 | 설명 |
|---|---|
| 회사명 | 지원 회사명을 태그 형태로 표시합니다. |
| 직무 | 지원 직무를 태그 형태로 표시합니다. |
| 자기소개서 제목 | 자기소개서 제목을 표시합니다. |
| 질문 | 사용자가 입력한 자기소개서 문항을 표시합니다. |
| 내가 쓴 자기소개서 | 사용자가 작성한 원본 자기소개서 내용을 표시합니다. |
| AI 리포트 | AI가 분석한 첨삭 결과를 표시합니다. |
| 자기소개서 VS AI 첨삭 | 원본 자기소개서와 AI 첨삭 내용을 비교해서 표시합니다. |
| 최종 작성본 | 사용자가 최종으로 수정한 자기소개서 내용을 표시합니다. |

#### 문항별 자기소개서 조회

자기소개서 문항이 여러 개인 경우 문항별로 내용을 구분하여 표시합니다.

- 각 문항은 카드 형태로 표시합니다.
- 문항 영역은 접기/펼치기 형태로 제공할 수 있습니다.
- 각 문항에는 질문, 원본 답변, AI 리포트, AI 첨삭 비교, 최종 작성본이 포함됩니다.
- 여러 문항이 있는 경우 세로 스크롤을 통해 전체 내용을 확인할 수 있습니다.

#### 최종 작성본 수정

사용자는 AI 첨삭 결과를 참고하여 최종 작성본을 수정할 수 있습니다.

- 최종 작성본 영역은 수정 가능한 TextArea로 제공합니다.
- 사용자가 내용을 수정하면 저장 버튼을 활성화합니다.
- 저장 전에는 현재 버전이 아직 반영되지 않은 상태로 처리합니다.
- 저장 완료 시 새로운 버전으로 저장합니다.

#### 저장 버튼 클릭

사용자가 `저장` 버튼을 클릭하면 자기소개서 저장 확인 모달을 표시합니다

해당 자기소개서를 저장하시겠습니까?
버전 V.0.1로 저장됩니다.

저장 완료 후 동작은 다음과 같습니다.

- 현재 최종 작성본을 저장합니다.
- 버전 정보가 생성됩니다.
- 버전 관리 영역에 새 버전이 추가됩니다.
- 저장 완료 상태를 사용자에게 안내합니다.

#### AI 첨삭 다시 받기

사용자가 `AI 첨삭 다시 받기` 버튼을 클릭하면 AI 첨삭 재요청 확인 모달을 표시합니다.

AI 첨삭을 다시 받으시겠습니까?
기존 버전은 저장됩니다.


| 항목 | 설명 |
|---|---|
| 아니오 | 모달을 닫고 상세 페이지에 머무릅니다. |
| 다시 받기 | 현재 내용을 기준으로 AI 첨삭을 다시 요청합니다. |

#### 첨삭 요구사항 작성

사용자는 자기소개서에 적용된 첨삭 요구사항을 작성할 수 있습니다.

- AI 첨삭 재요청 확인 모달의 확인 버튼을 누르면 첨삭 요구사항 모달을 표시합니다.
- 모달에는 사용자가 입력한 채용 공고 우대사항 또는 첨삭 요구사항을 표시합니다.
- `AI 첨삭 다시 받기` 버튼을 제공하여 요구사항 작성 후 바로 재첨삭을 요청할 수 있습니다

| 항목             | 설명                                    |
| -------------- | ------------------------------------- |
| 첨삭 요구사항        | 사용자가 첨삭 요구사항을 작성합니다. |
| AI 첨삭 다시 받기 버튼 | 현재 요구사항을 기준으로 AI 첨삭을 다시 요청합니다.        |


#### 버전 관리

저장된 자기소개서 버전을 확인할 수 있습니다.

- 상세 페이지 우측에 버전 관리 영역을 표시합니다.
- 저장된 버전 목록을 시간순으로 표시합니다.
- 각 버전에는 버전명과 저장 일시를 표시합니다.
- 사용자는 특정 버전을 선택하여 해당 버전의 자기소개서 내용을 확인할 수 있습니다.

| 항목    | 설명                          |
| ----- | --------------------------- |
| 버전명   | `v0.1`, `v0.2` 형식으로 표시합니다.  |
| 저장 일시 | 해당 버전이 저장된 날짜와 시간을 표시합니다.   |
| 선택 상태 | 현재 보고 있는 버전을 활성화 상태로 표시합니다. |


#### 삭제 버튼 클릭

사용자가 삭제 버튼을 클릭하면 자기소개서 삭제 확인 모달을 표시합니다.

| 메뉴       | 설명                            |
| -------- | ----------------------------- |
| 자기소개서 상세 | 현재 자기소개서 상세 내용을 확인합니다.        |
| 버전 관리    | 저장된 자기소개서 버전을 확인합니다.          |
| 삭제       | 자기소개서 삭제 확인 모달을 표시합니다.        |
| 키워드 분석   | 해당 자기소개서의 키워드 분석 페이지로 이동합니다.  |
| AI 면접    | 해당 자기소개서 기반 AI 면접 페이지로 이동합니다. |


### F-05: 자기소개서 키워드 분석(`/writing/[id]/keyword-analysis`)

#### 키워드 차트

키워드 빈도를 시각적으로 확인할 수 있도록 막대 차트로 표시합니다. 

#### 워드 클라우드 

자기소개서의 핵심 키워드를 버블 워드 클라우드 형태로 표시합니다. 

### F-06: 자기소개서 기반 AI 면접(`/writing/[id]/interview`)

#### 채팅형 면접 진행 

AI 면접은 채팅 UI 형태로 진행됩니다.

- AI가 자기소개서 기반 면접 질문을 제시합니다.
- 사용자는 하단 입력창에 답변을 입력합니다.
- 사용자가 답변을 전송하면 채팅 영역에 답변이 추가됩니다.
- AI는 사용자의 답변을 기반으로 피드백 또는 꼬리 질문을 제공합니다.

#### 음성 입력 

사용자는 마이크 버튼을 통해 음성으로 답변을 입력할 수 있습니다.
 
- 마이크 버튼 클릭 시 음성 입력을 시작합니다. 
- 음성 입력 결과를 텍스트로 변환하여 답변 입력창에 표시합니다. 
- 음성 입력 중에는 마이크 활성화 상태를 표시합니다.

## 6. 공통 컴포넌트

### Header

- 서비스 상단에 고정되어 로고와 주요 메뉴를 제공하는 공통 컴포넌트입니다. 
- 로그인 상태에 따라 `GuestHeader`와 `UserHeader`를 분리하여 사용합니다. 
- 스크롤 시 Header에 blur 효과를 적용합니다. 

#### GuestHeader - 비로그인 사용자에게 표시되는 Header입니다. 
- 로고, 로그인 버튼, 회원가입 버튼을 표시합니다. 
- 로고 클릭 시 랜딩 페이지(`/`)로 이동합니다. 

#### UserHeader 
- 로그인한 사용자에게 표시되는 Header입니다. 
- 로고, 사용자 프로필을 표시합니다. 
- 로고 클릭 시 자기소개서 목록(`/writing`)으로 이동합니다. 

#### Scroll Blur 
- Header는 화면 상단에 고정합니다. 
- 스크롤이 발생하면 반투명 배경과 blur 효과를 적용합니다. 
- 스크롤이 최상단일 경우 기본 스타일을 유지합니다.

### Footer

- 서비스 로고, 저작권, GitHub 링크를 표시합니다.

#### Logo

- 랜딩 페이지(`/`)에서는 `h1` 태그를 사용합니다.
- 내부 페이지에서는 heading 구조를 고려해 `div` 또는 `span` 태그로 표시합니다.
- 로고 클릭 시 로그인 상태에 따라 이동 경로가 달라집니다.

| 상태 | 이동 경로 |
|---|---|
| 로그인 상태 | `/writing` |
| 비로그인 상태 | `/` |

### Title

- 페이지 또는 섹션의 제목을 표시하는 컴포넌트입니다.
- 제목의 의미와 화면 구조에 따라 `h1`부터 `h6`까지의 heading 태그로 구현합니다.
- 기본 태그는 `h1`로 설정합니다.
- `as` 속성을 통해 heading 태그를 선택할 수 있습니다.
- 시각적 스타일과 HTML 태그는 분리해서 관리할 수 있습니다.

### Page Header

- 페이지의 상단에서 현재 화면의 제목과 설명을 표시하는 컴포넌트입니다.
- `title`은 페이지의 최상위 제목이므로 `h1` 태그로 표시합니다.
- `description`은 페이지 제목 아래에 보조 설명 문구로 표시합니다.
- `description`은 선택값이며, 없는 경우 제목만 표시합니다.

### Badge

- 회사명, 직무 등 자기소개서의 주요 분류 정보를 태그 형태로 표시하는 컴포넌트입니다.
- 라벨은 단독으로 사용할 수 있으며, 제목과 함께 조합하여 사용할 수도 있습니다.

### Button

- 사용자가 주요 액션을 실행할 수 있도록 제공하는 공통 버튼 컴포넌트입니다.
- 버튼은 동작 목적에 따라 Button 컴포넌트와 LinkButton 컴포넌트로 분리합니다.
- 스타일은 size, variant 속성을 기준으로 관리합니다.
- 버튼의 역할과 이동 여부를 명확히 구분하기 위해 as 방식보다는 Button과 LinkButton을 분리해서 사용합니다.
- 클릭 이벤트를 실행합니다.
- 버튼 타입에 따라 시각적 스타일을 다르게 표시합니다.
- 비활성화 상태를 지원합니다.
- 로딩 상태를 지원합니다.
- 버튼 내부에 텍스트 또는 아이콘을 표시할 수 있습니다.


### Input

- 한 줄 텍스트를 입력할 수 있는 공통 입력 컴포넌트입니다.
- 자기소개서 제목, 회사명, 직무, 공고 링크, 글자 수 입력 등에 사용합니다.
- 입력 목적에 따라 `type`을 다르게 설정할 수 있습니다.

### TextArea

- 여러 줄의 텍스트를 입력할 수 있는 공통 입력 컴포넌트입니다.
- 사용 목적에 따라 글자 수를 표시하는 버전과 표시하지 않는 버전으로 구분합니다.

### SideBar

- 자기소개서 상세 페이지, 키워드 분석 페이지, AI 면접 페이지에서 사용하는 사이드 메뉴 컴포넌트입니다.
- 현재 페이지 또는 선택한 메뉴는 활성화 상태로 표시합니다.

#### 사용 위치

| 페이지 | 표시 형태 |
|---|---|
| 자기소개서 상세 페이지 | 전체 메뉴 표시 |
| 키워드 분석 페이지 | 상세 메뉴 + AI 첨삭/키워드 분석 드롭다운 메뉴 표시 |
| AI 면접 페이지 | 상세 메뉴 + AI 면접 메뉴 표시 |

#### 메뉴 구성

| 메뉴 | 설명 | 이동 경로 |
|---|---|---|
| 메뉴 열기 | 사이드 메뉴를 펼치거나 접습니다. | - |
| AI 첨삭 | 자기소개서 상세 페이지로 이동합니다. | `/writing/[id]` |
| 키워드 분석 | 해당 자기소개서의 키워드 분석 페이지로 이동합니다. | `/writing/[id]/keyword-analysis` |
| 자기소개서 삭제 | 자기소개서 삭제 확인 모달을 표시합니다. | - |
| AI 면접 | 해당 자기소개서 기반 AI 면접 페이지로 이동합니다. | `/writing/[id]/interview` |
